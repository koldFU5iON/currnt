# Shared Utilities

## Purpose

Utilities are capabilities used across currnt. They should strengthen the main loop rather than become a scattered collection of tools.

## Job assessment

Assessment is shared intelligence connecting the career record, an opportunity, salary context, and application-document strategy. It should be reusable wherever an opportunity is viewed, without forcing the user through a separate tool.

## Salary context

Salary information should begin with what the employer actually states. If currnt offers an estimate, it must be plainly labeled as an estimate and show the assumptions behind it: location, role level, currency, pay period, and confidence.

It should help a user compare an opportunity with their own expectations. It should not imply market certainty where no reliable data exists.

## PDF export

Export should preserve the document the user approved. It should be available from the document workspace, with the page view serving as an honest preview of the final output.

## Capture

Capture is a utility shared by job tracking and assessment. The experience should remove friction from saving an opportunity without creating a second, disconnected inbox.

## Source and provenance

Whenever currnt derives, imports, extracts, or estimates something, the user should be able to understand where it came from. This includes job-source information, imported career material, assessment conclusions, salary estimates, and AI suggestions.

## How utilities should feel

- Present when useful, quiet when not.
- Integrated into the task at hand.
- Clear about limits and confidence.
- Reliable enough to reduce manual checking, never so opaque that trust depends on blind faith.
