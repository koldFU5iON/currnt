# AI and Prompts

## Role of AI

AI is an optional reasoning and drafting partner. It helps the user work with a large amount of career context, assess a role, identify useful evidence, and improve documents. It does not become the owner of the user's career story or make irreversible changes by itself.

The product should remain useful for people who do not configure an AI provider. They can build a profile, capture jobs, write documents, and export PDFs manually. AI should enrich these workflows, not gate them.

## How AI should behave

- Be specific about the evidence it used.
- Distinguish facts from inference, estimates, and suggestions.
- Prefer small, reviewable changes over replacing work wholesale.
- Ask for or expose missing context rather than inventing certainty.
- Explain why it recommends pursuing, avoiding, including, or changing something.
- Keep the user in control of when data is sent to a provider.

## Prompts as product material

Prompts shape the product's judgment and voice. They should be readable, inspectable, and modifiable by the user without making the product fragile.

The user should be able to understand:

- What the prompt is intended to do.
- Which career and job information it receives.
- Which parts they can safely change.
- Which prompt version produced an assessment or document suggestion.
- How to return to a trustworthy default.

Prompt changes should be deliberate. A malformed or incomplete prompt should not silently produce degraded work.

## Connected intelligence

The same career evidence should be reusable across assessment and writing, but each use has a different purpose:

- Assessment asks whether the evidence supports the opportunity.
- CV work asks which evidence should be visible and in what order.
- Cover-letter work asks how to make a personal, credible argument from that evidence.

These should feel connected to the user while remaining clear about what was generated for each task.

## How it should feel

- Transparent, calm, and capable.
- Never breathless about AI.
- More like an informed editor and analyst than an autopilot.
- Honest enough to say "I do not know" or "this needs your judgment."
